# Some QOL improvements for Acode. 

## Customizing
If you want to customize the patches	applied fork this fork, delete the patches you don't want and run "Build Acode APK" in the workflow menu under the Actions tab. 

## Installing
Got to the Actions tab and select the latest workflow under "Build Acode APK". 

# Current patches

|Patch               |Description|
|--------------------|--------------------|
|Storage fix         |Fixes storage bugs such as deleting failures and full file access for Alpine|
|Paste quicktool     |Replaces the "!" on the second page of keybinds with a paste button|
